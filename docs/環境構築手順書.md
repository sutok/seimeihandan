## 🧪 テスト環境構築

### 1. 自動テスト環境

#### 1.1 GitHub Actions設定

`.github/workflows/ci.yml`:
```yaml
name: CI/CD Pipeline
on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main ]

jobs:
  backend-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - uses: actions/setup-python@v4
      with:
        python-version: '3.9'
    - name: Install dependencies
      run: |
        cd functions
        pip install -r requirements.txt
    - name: Run API tests
      run: |
        cd test
        python test_api.py

  frontend-test:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v3
    - uses: actions/setup-node@v3
      with:
        node-version: '18'
    - name: Install dependencies
      run: |
        cd frontend
        npm install
    - name: Run build test
      run: |
        cd frontend
        npm run build
```

#### 1.2 ローカル継続的テスト

```bash
# テスト自動実行スクリプト作成
cat > scripts/test-watch.sh << 'EOF'
#!/bin/bash
# ファイル変更を監視してテスト自動実行
while inotifywait -e modify -r functions/ test/; do
    echo "ファイル変更を検出..."
    cd test && python test_api.py
done
EOF

chmod +x scripts/test-watch.sh
```

## 🔧 トラブルシューティング

### よくある問題と解決方法

#### 1. Python関連の問題

**問題**: `jamdict` インストールエラー
```bash
# 解決方法
pip install --upgrade pip setuptools wheel
pip install jamdict jamdict-data
```

**問題**: 仮想環境でモジュールが見つからない
```bash
# 解決方法
which python  # パスを確認
pip list      # インストール済みパッケージ確認
```

**問題**: SQLite スレッドエラー
```
⚠️ jamdict検索エラー: 田 - SQLite objects created in a thread can only be used in that same thread
```
```bash
# 解決方法
# 最新のmain.pyでは thread-local jamdict により解決済み
# 確認方法: 複数同時リクエストのテスト
for i in {1..3}; do
  curl -s -X POST http://localhost:8080/api/v1/analyze \
    -H "Content-Type: application/json" \
    -d '{"lastName":"田中","firstName":"太郎"}' | grep -o '"success":[^,]*' &
done
wait
# 全て "success": true を返すことを確認
```

#### 2. Node.js関連の問題

**問題**: `npm install` でエラー
```bash
# 解決方法
npm cache clean --force
rm -rf node_modules package-lock.json
npm install
```

**問題**: ポート3000が使用中
```bash
# 解決方法
lsof -ti:3000 | xargs kill -9  # macOS/Linux
npm start -- --port 3001        # 別ポート使用
```

#### 3. API接続の問題

**問題**: CORS エラー
```javascript
// functions/main.py で確認
headers = {
    'Access-Control-Allow-Origin': '*',
    'Access-Control-Allow-Methods': 'POST',
    'Access-Control-Allow-Headers': 'Content-Type'
}
```

**問題**: API応答が遅い
```bash
# jamdict初期化確認
python -c "from jamdict import Jamdict; jam = Jamdict()"
# タイムアウト設定調整
```

#### 4. GCPデプロイの問題

**問題**: Functions デプロイエラー
```bash
# ログ確認
gcloud functions logs read seimei-handan --region $REGION
```
