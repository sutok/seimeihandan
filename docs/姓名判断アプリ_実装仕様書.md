# 姓名判断アプリ - 実装仕様書

## 📋 プロジェクト概要

### プロジェクト名
**姓名判断アプリ**（Seimei Handan App）

### 目的
個人向け姓名判断サービス - 五格説に基づく画数計算による吉凶判定システム

### 対象ユーザー
- **メインターゲット**: 一般個人ユーザー
- **将来展開**: 企業向けサービス（当面は対象外）

---

## 🎯 機能要件

### 1. コア機能
- **姓名入力**: 姓・名の分離入力フォーム
- **文字処理**: 漢字・ひらがな混在対応
- **画数計算**: 康熙字典準拠 + ひらがな画数
- **五格判定**: 天格・人格・地格・外格・総格の計算
- **吉凶表示**: 6段階判定結果 + 簡単な説明文

### 2. 入出力仕様
#### 入力
- **姓**: 漢字・ひらがな（1-10文字）
- **名**: 漢字・ひらがな（1-10文字）
- **操作**: 送信ボタンクリック

#### 出力
- **画数表示**: 各文字の画数詳細
- **五格結果**: 天格・人格・地格・外格・総格の数値
- **吉凶判定**: 大吉・吉・中吉・小吉・凶・大凶
- **説明文**: 各格に対する簡潔な解説

---

## 🏗️ システム構成

### アーキテクチャ概要
```
React フロントエンド
     ↓ HTTPS POST
API Gateway / Load Balancer
     ↓ 内部API
GCP Cloud Functions v1
     ↓ SQLite読込
jamdict + KanjiDic2
     ↓ 辞書データ
康熙字典準拠 + ひらがな画数データ
```

### 技術スタック
- **フロントエンド**: React.js (styled-components)
- **バックエンド**: Google Cloud Functions v1 (Python)
- **辞書ライブラリ**: jamdict + KanjiDic2 
- **API**: RESTful API設計
- **データ形式**: JSON

## 📊 データ仕様

### 1. 康熙字典辞書
```json
{
  "漢字辞書": {
    "愛": {"stroke": 13, "reading": ["アイ"], "type": "kanji"},
    "美": {"stroke": 9, "reading": ["ビ", "ミ"], "type": "kanji"},
    "子": {"stroke": 3, "reading": ["シ", "ス", "こ"], "type": "kanji"}
  }
}
```

### 2. ひらがな辞書
```json
{
  "ひらがな辞書": {
    "あ": {"stroke": 3, "type": "hiragana"},
    "い": {"stroke": 2, "type": "hiragana"},
    "う": {"stroke": 2, "type": "hiragana"},
    "え": {"stroke": 2, "type": "hiragana"},
    "お": {"stroke": 3, "type": "hiragana"}
  }
}
```

### 3. 吉凶判定テーブル
```json
{
  "判定ルール": {
    "天格": {
      "1": "大凶", "2": "凶", "3": "大吉", "4": "凶",
      "5": "大吉", "6": "大吉", "7": "吉", "8": "吉"
    },
    "人格": { /* 同様の構造 */ },
    "地格": { /* 同様の構造 */ },
    "外格": { /* 同様の構造 */ },
    "総格": { /* 同様の構造 */ }
  }
}
```

### 4. データサイズ想定
- **jamdict辞書**: KanjiDic2 全13,108字 → 約10-50MB
- **ひらがな辞書**: 81字（濁音含む） → 約3KB
- **判定テーブル**: 81通り × 5格 → 約15KB
- **合計**: 約10-50MB（高品質・完全辞書）
